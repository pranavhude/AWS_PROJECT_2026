ROUTING
=======

Public Subnets:
  0.0.0.0/0 -> Internet Gateway

Private Application Subnets:
  0.0.0.0/0 -> NAT Gateway (when enabled)

Database Subnets:
  No default internet route
  Local VPC communication remains available


AVAILABILITY AND RESILIENCE
===========================

- Deploy public and private subnets across two Availability Zones.
- For production high availability, use one NAT Gateway per AZ.
- A single NAT Gateway reduces cost but introduces an AZ dependency.
- Keep ECS EC2 instances in private subnets.
- Configure security groups separately for NLB, ALB, ECS, and databases.
- Configure NLB and ALB listeners, target groups, and health checks
  in their respective Terraform modules.


IMPORTANT
=========

This module creates the VPC network foundation only.

It does not create:
- NLB or ALB
- Security groups
- ECS cluster, service, or tasks
- Auto Scaling Group or Capacity Provider
- RDS resources
- VPC endpoints
